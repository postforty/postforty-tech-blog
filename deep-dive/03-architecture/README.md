# Module 3. 소프트웨어 아키텍처 및 시스템 설계 (7~9주차)

도메인 모델링부터 클린 아키텍처, 대규모 트래픽 분산 처리까지 확장 가능한 소프트웨어를 설계하는 모듈이다.

## 주차별 학습 주제
- **7주차**: [도메인 주도 설계(DDD)와 계층 분리](week07_domain_driven_design.md)
  - 바운디드 컨텍스트, 엔티티, 밸류 객체, 애그리거트 루트
  - 비대한 Service/Controller 계층의 도메인 리팩토링
- **8주차**: [의존성 규칙과 프런트엔드 구조 설계](week08_clean_architecture_and_frontend.md)
  - 헥사고날 / 클린 아키텍처(DIP)
  - 프런트엔드 상태 성격 분리 및 Headless 패턴
- **9주차**: [대규모 트래픽 시스템 디자인](week09_large_scale_system_design.md)
  - 캐싱 전략(Look-aside) 및 캐시 스탬피드 방어
  - 메시지 브로커(Kafka, RabbitMQ) 비동기 디커플링 및 CQRS
